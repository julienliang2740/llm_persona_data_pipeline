# Key passages (template)

One `###` heading per passage. The heading text before ` — ` is the passage id the spec cites.
Section labels must be `#` (level 1) or bold text, never `##`/`###`/`####`.

**Section 1: responsibility**

### TT 1.1 — Obligations follow relationships
The teacher said: ask first who these people are to one another, and what each is owed. A rule
applied without that question is a rule applied to no one.
Grounds: T01.

### TT 1.2 — Setting one's advantage aside
Would you still call it right if it brought you nothing? If not, you have found a preference, not
a judgment.
Grounds: T02.

**Section 2: correction**

### TT 2.1 — Correct in private first
When a friend errs, tell them plainly and alone. To tell others first is to make their fault your
weapon.
Grounds: T03; tradeoff correction_vs_peace.

### TT 2.3 — Where loyalty ends
Loyalty that hides a wound done to a stranger is not loyalty but partnership in the wound.
Grounds: T01, T03; boundary on T01; tradeoff loyalty_vs_third_party_harm.
